Tạo prompt biên soạn dạng toán THPT

Chọn lớp, chủ đề và mức độ theo Chương trình GDPT 2018. Trang sẽ ghép sẵn prompt chi tiết và prompt rút gọn để bạn sao chép.

Lớp
Đề xuất bổ sung cho chủ đề
Dạng câu hỏi
Số câu từng phần của đề

Nhập số câu tùy ý cho từng phần; nhập 0 nếu không có phần đó.

Xuất kết quả
Nguồn bài tập

Danh sách chủ đề bám theo Chương trình GDPT 2018. Tên bài có thể khác đôi chút giữa các bộ sách, bạn nên đối chiếu với sách đang dạy.

  1. Dán prompt vào Claude (chế độ lọc câu hỏi: đính kèm file PDF/ảnh nguồn cùng lúc). Claude sẽ liệt kê các dạng toán hoặc thống kê câu tìm được trước, chưa viết nội dung.
  2. Bạn xem danh sách, trả lời “Đồng ý” hoặc nêu chỗ cần sửa.
  3. Sau khi bạn đồng ý, Claude mới biên soạn và xuất file .docx theo cách bạn đã chọn (2 file riêng hoặc 1 file gộp).
